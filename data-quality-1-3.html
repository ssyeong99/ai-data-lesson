좋은 데이터 vs 나쁜 데이터
데이터 품질 평가 — 분석 전 반드시 확인해야 할 것들
아무리 많은 데이터가 있어도, 데이터의 품질이 나쁘면 분석 결과도 엉터리가 됩니다.
"쓰레기가 들어가면 쓰레기가 나온다(Garbage In, Garbage Out)"라는 유명한 격언이 있을 정도예요.
🔑 핵심 개념
GIGO 원칙 — Garbage In, Garbage Out
아무리 뛰어난 분석 도구(AI 포함)를 써도, 입력 데이터가 엉망이면 결과도 엉망입니다.
데이터 품질 확인은 모든 분석의 첫 번째 단계입니다.
📐
데이터 품질의 5가지 기준
✅
완전성
결측치(누락된 값)이 없는가?
나쁜 예: 빈 칸이 많은 설문 결과
🎯
정확성
값이 정확하고 이상치(정상 범위를 크게 벗어난 값)가 없는가?
나쁜 예: 나이 -5세, 키 300cm
🔄
일관성
같은 기준으로 기록되었는가?
나쁜 예: 2026/01/01, 1월 2일, Jan 3 혼용
⏰
최신성
충분히 최근 데이터인가?
나쁜 예: 2010년 물가로 2026년 분석
🚫
중복 없음
불필요하거나 같은 데이터가 반복되지 않는가?
나쁜 예: 한 사람이 두 번 기록됨
🔧
데이터 정제 3단계 프로세스
STEP 1
불필요하거나 중복된 데이터가 포함되어 있는가?
  • 필요하지 않은 속성(열) 삭제
  • 중복된 행 찾아서 하나만 남기기
  • 문제 해결에 필요한 속성만 선별
STEP 2
데이터에 결측치(누락된 값)가 있는가?
  • 결측치 위치 확인
  • 해당 행 삭제하기
  • 평균·중앙값·최빈값으로 대체 입력
STEP 3
정상 범위에서 많이 벗어난 이상치가 있는가?
  • 이상치 위치 확인
  • 명백한 오류면 삭제
  • 의미 있는 값이면 대체 값 입력

  • 전문가에게 확인하기

  • 필요하지 않은 속성(열) 삭제
  • 통일된 형식으로 변환하기

생각해보기
결측치가 있는 데이터를 무조건 삭제하면 될까요? 만약 200명 중 50명의 응답이 비어 있다면, 삭제하면 150명의 데이터만 남습니다. 비어 있는 응답에 패턴이 있을 수도 있어요. (예: 남학생만 응답을 안 했다면?) 무작정 삭제보다는, 왜 비어 있는지 먼저 생각해보는 것이 중요합니다.
이번 레슨에서 배운 것
  • GIGO 원칙: 나쁜 데이터 → 나쁜 결과, 품질 확인이 분석의 첫 단계
  • 데이터 품질 5기준: 완전성, 정확성, 일관성, 최신성, 중복 없음
  • 정제 3단계: 불필요·중복 제거 → 결측치 처리 → 이상치 처리
  • 결측치: 누락된 값 — 삭제 또는 대체 값 입력
  • 이상치: 정상 범위를 크게 벗어난 값 — 삭제 또는 대체 값 입력
