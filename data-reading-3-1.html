데이터 읽기 기초
인터랙티브 테이블 탐색
데이터 리터러시의 첫 번째 실전 능력은 데이터 테이블을 읽는 것입니다. 스프레드시트, 통계 자료, 연구 보고서… 우리가 마주하는 데이터의 대부분은 행(row)과 열(column)으로 구성된 표 형태입니다.

이번 레슨에서는 200명 학생의 설문 데이터를 직접 탐색하면서, 데이터를 읽고 원하는 정보를 찾아내는 방법을 배워보겠습니다.
📐
핵심 개념
📋 데이터 테이블의 구조
  • 행(row)가로줄. 하나의 관측 대상(예: 학생 1명)에 대한 모든 정보.
  • 열(column)세로줄. 하나의 특성(예: 수면 시간)에 대한 모든 값.
  • 셀(cell)행과 열이 만나는 칸. 특정 대상의 특정 값 (예: 학생 1번의 수면 시간 = 7.5시간).
🗂️
데이터 테이블의 구조

아래에 200명 학생의 학교생활 설문 데이터가 있습니다. 이 데이터에는 어떤 열(변수)들이 있을까요?

열 이름의미데이터 유형예시
id학생 고유 번호식별자1, 2, 3…
grade학년범주형(순서)1, 2, 3
gender성별범주형남, 여
smartphone_hours하루 스마트폰 사용 시간수치형(연속)3.6
sleep_hours하루 수면 시간수치형(연속)7.5
fatigue피로도 (0: 낮음 ~ 높음)수치형(순서)0, 1, 2…
satisfaction학교생활 만족도 (1~10)수치형(순서)5
exercise_days주간 운동 일수수치형(이산)4
study_hours하루 공부 시간수치형(연속)3.2
TIP
데이터 테이블을 처음 볼 때는 바로 숫자를 보지 말고, 먼저 열 이름(변수)을 확인하세요. "이 데이터에는 어떤 정보가 담겨 있는가?"를 파악하는 것이 첫 번째 단계입니다.

정렬(Sort)로 데이터 탐색하기

정렬은 데이터를 특정 열의 값을 기준으로 순서대로 나열하는 것입니다.

🔼
오름차순 (Ascending)
작은 값에서 큰 값 순으로 정렬
예) 수면 시간: 4.5 → 5.0 → 6.2 → …
🔽
내림차순 (Descending)
큰 값에서 작은 값 순으로 정렬
예) 수면 시간: … → 9.0 → 8.5 → 8.0
💭 생각해보기
  • 어떤 학생이 스마트폰을 가장 많이/적게 사용하는가?
  • 만족도가 가장 높은/낮은 학생의 다른 특징은?
  • 데이터에 비정상적으로 크거나 작은 값(이상치)이 있는가?
실습 2 정렬로 정보 찾기
▲ 접기

위의 데이터 탐색기에서 열 이름을 클릭하여 정렬해보고, 아래 질문에 답해보세요. (열 이름을 한 번 클릭하면 오름차순, 한 번 더 클릭하면 내림차순입니다.)

스마트폰 사용 시간(smartphone_hours)이 가장 긴 학생의 사용 시간은?정답 보기 ▼
smartphone_hours 열을 내림차순 정렬(두 번 클릭)하면 찾을 수 있습니다. 탐색기에서 직접 확인해보세요!
수면 시간(sleep_hours)이 가장 짧은 학생은 하루에 몇 시간 자나요?정답 보기 ▼
sleep_hours 열을 오름차순 정렬(한 번 클릭)하면 최솟값이 맨 위에 옵니다. 탐색기에서 직접 확인해보세요!
만족도(satisfaction)가 10인 학생은 대략 몇 명인가요?정답 보기 ▼
satisfaction 열을 내림차순 정렬한 뒤 10인 행이 몇 개인지 세어보세요. 또는 검색창에 10을 입력해볼 수도 있습니다.
🔍
필터링(Filter)으로 데이터 좁히기

필터링은 특정 조건에 맞는 데이터만 골라서 보는 것입니다. 탐색기 상단의 검색창에 원하는 값을 입력하면 해당 값이 포함된 행만 표시됩니다.

참고
전문적인 분석 도구(엑셀, Python 등)에서는 더 정교한 필터링이 가능합니다. 예: "스마트폰 사용 시간이 5시간 이상이면서 수면 시간이 6시간 미만인 학생". 지금은 기본 텍스트 검색 필터를 연습합니다.
실습 3 필터링으로 탐색하기
▲ 접기

데이터 탐색기의 검색창을 활용하여 아래 질문에 답해보세요.

검색창에 "남"을 입력하면 몇 명의 데이터가 표시되나요?정답 보기 ▼
성별이 "남"인 학생의 데이터가 표시됩니다. 탐색기 상단의 행 수 표시를 확인해보세요.
검색창에 "3"을 입력하면 어떤 일이 생기나요? 이것이 의미하는 바는?정답 보기 ▼
"3"이 포함된 모든 행이 표시됩니다. 학년 3뿐 아니라 smartphone_hours, study_hours 등에 3이 들어간 행도 포함됩니다. 단순 텍스트 검색은 의도하지 않은 결과를 포함할 수 있으므로 결과를 항상 확인해야 합니다.
📊
열 통계로 전체 그림 파악하기

데이터를 한 행씩 보는 것만으로는 전체적인 흐름을 파악하기 어렵습니다. 탐색기 하단의 열 버튼을 클릭하면 해당 열의 요약 통계를 볼 수 있습니다.

통계량의미
개수(Count)결측값을 제외한 데이터의 수
평균(Mean)모든 값의 합 ÷ 개수
중앙값(Median)값을 순서대로 나열했을 때 한가운데 값
표준편차(Std)값들이 평균에서 얼마나 퍼져 있는지
최솟값(Min)가장 작은 값
최댓값(Max)가장 큰 값
TIP
범주형 열(예: gender)을 클릭하면 각 범주의 빈도(frequency)가 막대 그래프로 표시됩니다.
실습 4 열 통계 읽기
▲ 접기

탐색기 하단의 열 버튼을 클릭해서 통계를 확인하고 아래 질문에 답해보세요.

sleep_hours의 평균과 중앙값은 각각 얼마인가요?정답 보기 ▼
sleep_hours 버튼을 클릭하면 통계가 나옵니다. 평균과 중앙값이 비슷하다면 데이터가 비교적 대칭적으로 분포한다는 뜻입니다.
smartphone_hours의 표준편차는 얼마인가요? 이것이 의미하는 바는?정답 보기 ▼
표준편차가 크면 학생마다 스마트폰 사용 시간의 차이가 크다는 뜻이고, 작으면 비슷하다는 뜻입니다.
gender(성별) 열을 클릭하면 남녀 비율은 어떻게 되나요?정답 보기 ▼
gender 버튼을 클릭하면 남/여 각각의 빈도가 막대 그래프로 표시됩니다. 대략 절반씩인지, 한쪽이 더 많은지 확인해보세요.

데이터 읽기 체크리스트
1
크기 확인
몇 행(관측 수) × 몇 열(변수 수)인가?
2
열 이름 확인
각 열이 무엇을 의미하는지 파악
3
데이터 유형 확인
수치형인가, 범주형인가?
4
요약 통계 확인
평균, 중앙값, 최솟값, 최댓값, 분포
5
이상한 값 확인
비정상적으로 크거나 작은 값, 빈 값은 없는지?
주의
데이터를 "읽는다"는 것은 단순히 눈으로 보는 것이 아닙니다. 구조를 파악하고, 값의 범위를 확인하고, 이상한 점을 발견하는 것까지 포함합니다.
