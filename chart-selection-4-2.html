올바른 차트 선택하기
데이터 유형별 차트 매칭
차트를 읽을 줄 아는 것도 중요하지만, 올바른 차트를 선택하는 능력은 더욱 중요합니다. 잘못된 차트를 선택하면 데이터의 핵심 메시지가 왜곡되거나 숨겨질 수 있습니다.

이번 레슨에서는 데이터의 특성에 따라 어떤 차트가 적합한지 판단하는 방법을 배웁니다.
핵심 원칙
"데이터로 하고 싶은 이야기가 무엇인가?"를 먼저 정하고, 그 이야기에 가장 잘 맞는 차트를 선택합니다.
📊
주요 차트 유형과 용도
📊막대 차트
언제? 범주별 크기를 비교할 때
데이터: 범주형(X) + 수치형(Y)
과목별 성적 · 반별 학생 수 · 브랜드별 판매량
📈꺾은선 차트
언제? 시간에 따른 변화를 보여줄 때
데이터: 시간(X) + 수치형(Y)
월별 기온 변화 · 연도별 인구 · 일별 주가
🥧원형 차트
언제? 전체 대비 비율을 보여줄 때
데이터: 범주형 + 비율
교통수단 비율 · 예산 구성 · 시장 점유율
🔵산점도
언제? 두 수치 변수의 관계를 볼 때
데이터: 수치형(X) + 수치형(Y)
키와 몸무게 · 공부 시간과 성적 · 온도와 아이스크림 판매량
📶히스토그램
언제? 수치 데이터의 분포를 볼 때
데이터: 수치형 하나의 분포
시험 점수 분포 · 키 분포 · 나이 분포
🗺️
차트 선택 의사결정 가이드

아래 질문을 순서대로 따라가면 적절한 차트를 찾을 수 있습니다.

Q1
비교하려는 것이 "시간에 따른 변화"인가요?
YES → 꺾은선 차트 NO → 다음 질문으로
Q2
전체에서 각 부분의 "비율"을 보고 싶은 건가요?
YES → 원형 차트 (항목 5개 이하일 때) NO → 다음 질문으로
Q3
두 수치형 변수 사이의 "관계"를 보고 싶은 건가요?
YES → 산점도 NO → 다음 질문으로
Q4
하나의 수치형 변수의 "분포"를 보고 싶은 건가요?
YES → 히스토그램 NO → 다음 질문으로
Q5
범주별 값의 "크기"를 비교하고 싶은 건가요?
YES → 막대 차트 NO → 상황에 맞는 차트를 다시 생각해보세요
실습 1직접 차트를 골라보세요
▲ 접기

시나리오가 주어지면, 가장 적합한 차트 유형을 선택하세요. 선택한 차트를 미리 볼 수 있습니다!

🔗
데이터 유형과 차트 매칭

데이터의 유형을 보고 어떤 차트가 적합한지 판단하는 연습을 해봅시다.

실습 2데이터를 알맞은 차트에 분류하기
▲ 접기

아래 데이터 상황을 드래그하여 적합한 차트 유형에 놓으세요. 모두 배치한 후 정답 확인 버튼을 누르세요.

💡 정답 숨기기
급식 만족도 변화(2020~2025) → 꺾은선: 시간에 따른 추세
혈액형 비율 → 원형: 전체 대비 비율 (항목 4개)
키와 달리기 기록 → 산점도: 두 수치형 변수의 관계
반별 봉사활동 시간 → 막대: 범주별 크기 비교
수학 점수 분포 → 막대(히스토그램): 수치 분포 표현
동아리별 가입자 수 → 막대: 범주별 크기 비교
🔎
잘못된 차트 선택 찾기

실제로 많은 뉴스나 보고서에서 부적절한 차트가 사용됩니다. 잘못된 차트 선택을 비판적으로 판단하는 연습을 해봅시다.

실습 3이 차트 선택, 괜찮을까?
▲ 접기

각 상황에서 사용된 차트가 적절한지 판단해보세요.

상황: "10년간 서울 인구 변화를 원형 차트로 표현했다."
이 차트 선택에 문제가 있을까요?
✅ 시간에 따른 변화는 꺾은선 차트가 적합합니다. 원형 차트는 한 시점의 비율을 보여줄 때 사용하므로 10년간의 추세를 보기 어렵습니다.
상황: "반별 학생 수를 막대 차트로 표현했다."
이 차트 선택에 문제가 있을까요?
✅ 범주(반)별 수치(학생 수)를 비교하는 것이므로 막대 차트가 적합합니다!
상황: "학생 5명의 키와 몸무게 관계를 원형 차트로 표현했다."
이 차트 선택에 문제가 있을까요?
✅ 두 수치형 변수(키, 몸무게)의 관계를 보려면 산점도가 적합합니다.
상황: "전교생의 좋아하는 계절 비율을 원형 차트로 표현했다."
이 차트 선택에 문제가 있을까요?
✅ 범주(계절)가 4개이고, 전체 대비 비율을 보여주는 것이므로 원형 차트가 적합합니다!
TIP
차트 선택에서 가장 흔한 실수 세 가지:
1. 시간 변화 데이터를 원형 차트로 그리기 (꺾은선이 적합)
2. 너무 많은 항목(10개 이상)을 원형 차트에 넣기
3. 두 변수의 관계를 막대 차트로 그리기 (산점도가 적합)
